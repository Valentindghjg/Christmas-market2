## Goal
A Shop button opens a panel with the reference's categories; every product shows its name, description, price and Buy, Owned or Coming soon. Buy only asks the server to prompt. VIP holders get a chat tag. The owner has a checklist of every product to create.

## Steps
1. **ShopPanel.client.lua** (pattern of `TeamPanel.client.lua`): ScreenGui `ShopUI` (display order 15); rail button `ShopButton` (`UiKit.addRailButton("ShopButton", "shopButton", 20)`), visible only while `CompanyReady == true`; it toggles the panel. Panel `ShopPanel` (Panel colour, `UiTheme.CornerRadius.Panel`, padding 12) placed by `UiKit.bindDialog(gui, {frame, list, footer}, UiTheme.Dialogs.Shop)`.
   - `Title` (`shopTitle`, 22 px, height 30). `CategoryBar`: horizontal ScrollingFrame at y 38, height `UiTheme.MinTouch`, one button `Category_<id>` per `ShopConfig.Categories` (text `shopCategory<id>`, width 120); selected Gold, others Sand; default `Starter`.
   - `ProductList` (vertical ScrollingFrame, UIListLayout padding 6), first entry `UiKit.listStatus(list, "ShopStatus")`. One row `Product_<key>` (Row colour, height 96) per product of the selected category in config order: `Name` (18 px), `Description` (13 px, wrapped, 2 lines), `Price` (`shopPrice` with the catalog price), `Action` button (140 × 44, right): `Buy` → `shopBuy`, Gold, active; `Owned` → `shopOwned`, Sand, `Active = false`, `AutoButtonColor = false`; `ComingSoon` → `shopComingSoon`, Sand, inactive. Row `BoostCashX2` adds `BoostLine` (`shopBoostActive`, mm:ss) while `cashBoostSeconds > 0`.
   - Description: `shopDescCash` is formatted with `UiTheme.formatMoney(grant.cash)`; all others are plain.
   - Footer: `Close` (`shopClose`, Sand, full width, 44 px).
   - Open: `UiKit.claimModal("Shop", close)`; status `shopLoading`; `UiKit.request(ShopAction, "Shop.Catalog", {})` and `UiKit.request(BusinessAction, "Company.GetSummary", {})` (boost line only); render. A failed catalog shows `shopErrorUnavailable` and no rows. Close: hide, `UiKit.releaseModal("Shop")`. Losing `CompanyReady` closes it.
   - While open, a change of `RobuxSpent` or any `ShopPass<Key>` attribute re-fetches the catalog; the boost line counts down locally once per second from the summary value.
   - Buy: one request in flight at a time; `Shop.Prompt {productKey}`; ok → status `shopPromptOpen`; error → status by code: `ComingSoon` → `shopErrorComingSoon`, `AlreadyOwned` → `shopErrorOwned`, `NoActiveSave` → `shopErrorNoSave`, `BoostFull` → `shopErrorBoostFull`, `RateLimited` → `shopErrorBusy`, anything else → `shopErrorUnavailable`. The client never calls MarketplaceService.
2. **ChatTags.client.lua**: if `TextChatService.OnIncomingMessage` is already assigned by another script, stop and report. Else assign a callback: for a message with `TextSource`, if `Players:GetPlayerByUserId(TextSource.UserId)` has attribute `ShopPassVip == true`, return `TextChatMessageProperties` with `PrefixText = '<font color="#' .. UiKit.Colors.Gold:ToHex() .. '">[VIP]</font> ' .. message.PrefixText`; otherwise return nil.
3. **ShopConfig.textKeys** as in Data.
