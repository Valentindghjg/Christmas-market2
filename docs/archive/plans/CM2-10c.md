**RockCluster** (keys StoneGray, StoneGrayShade, SnowWhite): 3 rocks with `map_common.rock`: an icosahedron subdivided once (80 faces), vertices scaled by the half-extents and jittered +-12 % (K.seed), created through `hq_common.mesh`; faces with normal z > 0.6 → SnowWhite, normal z < -0.1 → StoneGrayShade, others StoneGray (one object per key). Half-extents and centres: (2.4, 1.8, 1.5) at (-1.2, 0.3, 1.2); (1.6, 1.4, 1.1) at (2.2, -0.8, 0.8); (1.0, 0.9, 0.7) at (1.4, 1.4, 0.5). Collider `COL_Rock` 6.6 x 4.0 x 2.2 at (0.1, 0, 0.8).

**Mountains** (`map_common.heightfield(spec)`; keys MountainRock, MountainRockShade, SnowWhite, SnowShade):
- Grid over the footprint (x from -W/2 to W/2, y from -L/2 to L/2, step s). Height z = max over summits of h x (1 - d)^1.3 - 12, with d = min(1, sqrt(((x - xs)/ax)^2 + ((y - ys)/by)^2)). Interior vertices jitter x, y +-0.25 s and z +-3 (K.seed); rim vertices and summit vertices do not jitter. Each cell is 2 triangles, diagonal alternating, wound counter-clockwise seen from above (normals up); cells whose 4 corners are all at -12 are dropped. Faces are grouped by key and each group is created with `hq_common.mesh(part, key, verts, faces, recalc=False)` (open surface; rocks use `recalc=True`).
- Face keys by centroid z (zc) and normal: zc < 4 → SnowWhite (snowy foot); zc >= snow line → SnowWhite if normal x <= 0 else SnowShade; otherwise MountainRock if normal x <= 0 else MountainRockShade.
- Collider `COL_Core` 20 x 20 x 20 at (0, 0, 10) (inside the mass, so the MeshParts do not collide; CM2-10W adds boundary walls).
