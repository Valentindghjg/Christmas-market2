## Steps
0. `lune run tools/art/art.luau doctor`; exit 1: stop, BLOCKED.
1. **Separate modeler runs**, reviewer commit after each: **B1** rows 1-6, **B2** rows 7-11, **B3** rows 12-13. Per model as CM2-10D steps 1-2; a failing model is reported, not committed.
2. Per batch: `rojo build release.project.json -o release.rbxlx`; `verify` -> **54 / 59 / 61 integrated**, 0 pending, 0 failed.
3. B1 writes the MODEL_INTEGRATION section (<= 16 lines): contract, wires/signs/lights, sums verbatim, then a measured row (W x L x H, tris/MP, colliders, Atts in model space) per model; B2, B3 add rows. DECISION_LOG entry likewise: paths, tiers, seeds, deviations.
4. Time stop: finish the current model, report the rest; the next run starts at the first unfinished row.
