## Goal
On phone, tablet and PC the player sees cash, reputation, day and lot status top right, opens a **Lot Manager** with the 6 reference tabs from a left button rail (or key M), and orders trees in its Supplier tab. The save picker, Team panel and teammate finder share one UI kit and fit a short landscape phone. Every control is ≥ 44 px and inside the safe area.

## Steps
1. **`src/shared/UiTheme.lua`** (`--!strict`, pure, no Instances): the data above plus
   - `export type Box = {x: number, y: number, w: number, h: number}`, `Metrics = {width, height, compact, margin, railWidth, railGap, railTop, railMaxHeight, showDay}`.
   - `metrics(width: number, height: number): Metrics` (floors inputs, clamps to ≥ 0).
   - `hudLayout(m: Metrics, railButtons: number): {hud: Box, chips: {{id: string, box: Box}}, status: Box, rail: Box, railScrolls: boolean, toast: Box, actionBar: Box, manager: Box}`. `hud = (W − m − stripW, m, stripW, 74)`; chips and `status = (0, 40, stripW, 34)` are relative to `hud`; `rail.h = min(n·44 + (n−1)·gap, railMaxHeight)`; chip ids `Cash`, `Reputation`, `Day` (omitted when `showDay` is false), `Lot`.
   - `managerLayout(m: Metrics, manager: Box): {padding, header, title, close, cash: Box?, tabBar, tabs: {Box}, body: Box, horizontal: boolean}` (`tabs` relative to `tabBar`, the rest relative to the content box).
   - `dialogLayout(m: Metrics, spec): {compact, frame, innerWidth, innerHeight, list: Box?, footer: Box?, leftWidth, rightHeader: Box?}` (no list or footer when `footerHeight = 0` and `listTop = 0`).
   - `formatMoney(value: number): string`: floors, thousands with ",", sign kept (`1615 → "1,615"`, `-1200 → "-1,200"`).
   - `overlaps(a: Box, b: Box): boolean` (positive-area intersection) and `inside(box: Box, width: number, height: number): boolean`.

3. **`src/client/UiKit.lua`** (`--!strict` ModuleScript; module state is shared by every LocalScript of the client):
   - `UiKit.Colors: {[string]: Color3}` from `UiTheme.Colors`; `UiKit.localized(key)`, `UiKit.localizedFormat(key, ...)` with today's locale rule (de or en, else en) in this one place, so CM2-43 changes one line.
   - `UiKit.screenGui(name: string, displayOrder: number): ScreenGui`: `ResetOnSpawn=false`, `ZIndexBehavior=Sibling`, `IgnoreGuiInset=false`, `ScreenInsets=CoreUISafeInsets`, `SafeAreaCompatibility=None`, `ClipToDeviceSafeArea=true`, parent PlayerGui.
   - Factories with today's exact defaults: `corner(parent, radius)`, `padding(parent, px)`, `label(parent, name, text, textSize, playerText: boolean?)` (GothamBold, Cream, transparent, left, `TextTruncate.AtEnd`; `playerText=true` → `AutoLocalize=false`), `button(parent, name, text, color, textSize: number?)` (DarkText, GothamBold, wrapped, corner 8, size default 15), `textBox(parent, name, placeholder)` (the picker's version, `AutoLocalize=false`).
   - AutoLocalize rule: `false` for save names, usernames, invite codes, company names, typed text and the cash and reputation chips; `true` for everything else.
   - `request(remote: RemoteFunction, action: string, payload): any`: `{version=1, requestId=GUID, action, payload}`, pcall; failure or a non-table → `{ok=false, errorCode="ConnectionError"}`.
   - `onLayout(gui: ScreenGui, callback: (UiTheme.Metrics) -> ()): RBXScriptConnection`: calls now and on every `AbsoluteSize` change.
   - Rail: `addRailButton(name: string, textKey: string, order: number): TextButton` creates once ScreenGui `HudRailUI` (DisplayOrder 5) → ScrollingFrame `Rail` (transparent, `ScrollBarThickness` 4, `AutomaticCanvasSize` Y, UIListLayout by `LayoutOrder`, padding = rail gap); buttons Sand, `Size (1, −6, 0, 44)`, start hidden. The rail box comes from `hudLayout` and is recomputed on resize and when a button's `Visible` changes. `setRailHidden(hidden: boolean)` hides the whole rail without touching button `Visible`.
   - Modals: `claimModal(id: string, close: () -> ())` closes the current other holder first; `releaseModal(id)`; `closeModals()` closes every holder. Holders: `LotManager`, `Team`, `Finder`. The picker is the base layer: its `open()` calls `closeModals()` and it never claims, so the finder still opens over it.
   - `bindDialog(gui, parts: {frame: Frame, list: GuiObject?, footer: Frame?, leftItems: {GuiObject}?, rightHeader: GuiObject?}, spec)`: on layout sets `AnchorPoint (0,0)`, `Position` and `Size` (pixel offsets) of frame, list and footer from `dialogLayout`; compact → each `leftItems` width = `leftWidth`, `rightHeader` = its box; regular → their original sizes and positions (stored at bind time).
4. **`src/client/LotManager.lua`**: `LotManager.new(gui: ScreenGui, context: TabContext, onOpenChanged: (open: boolean) -> ()): Manager` with `open()`, `close()`, `toggle()`, `isOpen(): boolean`, `select(tabId: string)`, `render(summary: any?)`, `applyLayout(m: Metrics, box: Box)`.
   - Instances: Frame `LotManager` (Panel, corner 14, `Active=true`, hidden) → `Title` (`lotManagerTitle`, 22), `CloseLotManager` (Sand, `lotManagerClose`), compact `ManagerCash` (`hudCash`, `playerText`), ScrollingFrame `TabBar` with `Tab_<id>` buttons (label key; selected Gold with a Cream `UIStroke` 3, others Sand), Frame `Body` with ScrollingFrame `Page_<id>` (transparent, `ScrollBarThickness` 6).
   - Default tab Supplier; the last tab stays selected while the session runs (not saved). Pages are built on first select: `script.Parent.LotManagerTabs:FindFirstChild(module)`; a missing module → a wrapped `Placeholder` label (`lotManagerTabSoon`); a failed `require` or `create` → `lotManagerTabError` and one `warn`.
   - Tab contract (exported types, written as a comment block for G7, 25/26, G9, 32/33 and 35): a module returns `{create: (page: ScrollingFrame, context: TabContext) -> TabHandle}`. `TabContext = {request: (action, payload) -> any, refresh: () -> (), summary: () -> any?}` (`request` goes through `BusinessAction` and never throws). `TabHandle = {render: (summary: any?) -> (), shown: ((visible: boolean) -> ())?}`. `render(nil)` means no data (loading or a switched save). A tab reads only its own summary sub-table (`pricing`, `staff`, `plot`, `analytics`, …) and must not error when it is missing. The tab sets its page's `CanvasSize`. Every `render` and `shown` call runs in `pcall`; an error `warn`s once per tab and never stops the HUD poll.
   - `open` claims modal `LotManager`; `close` releases it. Opening and closing calls `onOpenChanged`.
5. **`SupplierTab.lua`**: moves every supplier element, handler, busy flag and request of `UiController` unchanged (same names: `Species_<id>`, `OrderTrees`, `UnloadDelivery`, `PlaceTree`, `SellBackTree`), with `context.request` and `context.refresh`. On a successful order the detail line shows `orderAcceptedTruck` with the cost (the HUD cash is no longer overwritten).
