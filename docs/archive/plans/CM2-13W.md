## Goal
Every plot shows the CM2-13a HQ art of its tier and the CM2-13b counter, bays, bundles, lot fence and decor fences, fronts facing the road; without `.rbxm` the primitives stay. Rules and gameplay geometry are unchanged.

## Source of truth
Backlog CM2-13W and the MODEL tasks intro (wiring rules; owner 2026-11-25: numeric checks decide). MODEL_INTEGRATION "HQ art (CM2-13a)", "Lot props art (CM2-13b)", "Map in the world (CM2-10W)". Plans CM2-13a, CM2-13b, CM2-G9a, CM2-12W.

**Planner decisions**
- The backlog's "config tier `ChristmasPavilion` maps to `Buildings/TimberPavilion`" is obsolete: since schema 19 the tier ids are `SalesTent`, `TimberPavilion`, `AlpineHut`, `MountainChalet`, so the path is `Buildings/<tier.id>`.
- The lot fence follows `Progression.fenceBoxes` (8 studs per level, sides only from level 1, from z −27 back). The CM2-13b fence layout (6 per level, sides from z 27) is superseded. Only `FenceRail8` and `FencePost` are placed; `FenceRail6` is unused.
- Gameplay anchors stay. `CheckoutCounter.CounterBase` and `Receiving.Bay_<i>` keep their size, position and children (prompt, label) and become invisible when art is present.
- The decor fences (`Placement.DecorFences`) become one `FenceRail8` and one `FencePost` each, in a Model `DecorFence`. CC0 `FenceWooden` stays only as the fallback.

## Data and config
No new config key. **`LotArt`** (`--!strict`, `local GameConfig = require(script.Parent.GameConfig)`):

| Name | Value |
|---|---|
| `PATHS` | `{ Counter = "Props/CheckoutCounter", Bay = "Props/ReceivingBay", Bundle = "Props/TreeBundle", Rail = "Environment/FenceRail8", Post = "Environment/FencePost" }` |
| `RAIL_LENGTH` | 8 (FenceRail8 post spacing) |
| `RAIL_BEHIND`, `RAIL_AHEAD`, `PIECE_HALF` | 4.3, 3.95, 0.3. Rail extent behind and ahead of its centre along the run; half-width (MODEL_INTEGRATION 13b: start post at model +X = +L/2, rails to −X, 0.6 thick) |
| `FENCE_OFFSET` | 0.45 (fence line beyond the lot edge = centre of the 0.3-thick `fenceBoxes`) |
| `FENCE_BASE_DROP` | 0.55 (base = map ground top 0, behind the lot edge; never floats) |
| `BUNDLE_ROW`, `BUNDLE_SPACING` | 1.0, 1.2 (today's primitive stacking) |
| `COUNTER` | `{ x = 16, z = -14 }`, computed as the centre of `GameConfig.Customers.Npc.Path.Counter` |

Types: `Choice = { path: string, mode: string, template: any?, code: string? }`; `Piece = { box: string, kind: string, x: number, z: number, dirX: number, dirZ: number }` (lot frame; `kind` "Rail" or "Post").

## Steps
1. **`src/shared/LotArt.lua`** functions:
   - `hqLevel(level: any): number`: a non-number or NaN gives 1; else `math.clamp(math.floor(level), 1, GameConfig.Progression.HQ.maxLevel)`.
   - `hqPath(level: any): string` = `"Buildings/" .. tiers[hqLevel(level)].id`.
   - `hqCentre(level: any): (number, number)`: the centre of that tier's `footprint` ((−8, −4) for all four).
   - `roadYaw(facing: number): number`: `math.pi` if `facing == 1` (plots 1–3), else 0. Model −Z then points at the road.
   - `runYaw(dirX: number, dirZ: number, facing: number): number` = `math.atan2(dirZ * facing, -dirX)`. Model −X then points along the lot-frame run.
   - `choose(root: any, find: (any, string) -> (any, string?), path: string): Choice`: calls `find` once. A template gives mode "Art"; else mode "Primitive" with code = the returned code or "MissingArtAsset".
   - `fenceSegments(level: any): { Piece }`: `growth` = clamp(floor) 0..`LotExpansion.maxLevel` (a non-number or NaN gives 0). `half` = `LotHalfWidth`, `back` = `LotHalfDepth + BackDepthPerLevel × growth`, `zb = -(back + FENCE_OFFSET)`.
     - Back: for k = 0..9 (`2·half / RAIL_LENGTH`): Rail at `(-half + 8(k + 0.5), zb)`, dir (1, 0). Then a Post at `(half, zb)`, dir (1, 0).
     - If growth ≥ 1, for `Left` (x = −(half + 0.45)) and then `Right` (x = +(half + 0.45)): `growth × BackDepthPerLevel / RAIL_LENGTH` Rails at `z = -(LotHalfDepth + 0.45) - 8(k + 0.5)`, dir (0, −1). No end post: the rails end against the back run's corner post.
     - Count: 11 + 2·growth.
   - `decorPieces(x: number, z: number): { Piece }` = Rail `(x, z)` and Post `(x + 4, z)`, both dir (1, 0), box `"Decor"`.
   - `pieceBox(piece: Piece): { minX, maxX, minZ, maxZ }`:
     - Post: ±0.3 on both axes.
     - Rail: along the run from `centre − 4.3·dir` to `centre + 3.95·dir`, ±0.3 across.
   - `bundleOffset(k: number): (number, number)` = `(k // 3) × 1.0`, `-1.2 + (k % 3) × 1.2`. These are the rise above the deck and the world z offset.
2. **`src/server/Services/LotArtWorld.lua`** (requires ReplicatedStorage `ArtLibrary`, `LotArt`, `GameConfig`, and `script.Parent.LotFenceWorld`). `ctx` = `{ lotPosition, lotTop, facing, setCollisionGroup, group, reportMissing }` from WorldService.
   - Local `cloneArt(path, ctx): Model?`: `LotArt.choose(ArtLibrary.root(ReplicatedStorage), ArtLibrary.find, path)`. If not Art, call `ctx.reportMissing(path, code)` and return nil; else return `ArtLibrary.prepareClone(template)`.
   - `hq(plot: Model, level: number, ctx): Model?`:
     - path `LotArt.hqPath(level)`, then `cloneArt`; `Name = "StarterSalesTent"`.
     - Pivot: `PivotTo(CFrame.new(ctx.lotPosition(plot, cx, cz, ctx.lotTop(plot))) * CFrame.Angles(0, LotArt.roadYaw(ctx.facing(plot)), 0))` with `cx, cz = LotArt.hqCentre(level)`; `Parent = plot`.
     - Scale: `scale = ArtLibrary.fitScale(LotFenceWorld.worldExtents(model)` against footprint w × d`)`; if `scale < 1`, `ScaleTo(GetScale() × scale)`.
     - Attributes `FitScale = scale`, `HqArtMode = "Art"`, `HqArtPath = path`; `ctx.setCollisionGroup(model, ctx.group)`.
   - `counter(plot, ctx): Model?`: clone `PATHS.Counter`, `Name = "CheckoutCounter"`; pivot at `lotPosition(plot, LotArt.COUNTER.x, LotArt.COUNTER.z, lotTop)` × `roadYaw`; `Parent = plot`.
   - `bay(folder: Instance, plot: Model, index: number, base: Vector3, ctx): Model?`: clone `PATHS.Bay`, `Name = "BayArt_" .. index`, `PivotTo(CFrame.new(base) * roadYaw)`, `Parent = folder`.
   - `bundles(model: Model, bay: BasePart, count: number, ctx): boolean`:
     - Choose `PATHS.Bundle` once. If it is missing, report and return false.
     - For k = 0..count−1: clone, `Name = "Bundle"`, pivot `CFrame.new(bay.Position.X, bay.Position.Y + bay.Size.Y / 2 + rise, bay.Position.Z + dz)` (yaw 0, from `bundleOffset(k)`), `Parent = model`. Every BasePart gets `CanCollide = false`, `CanQuery = false`.
     - Return true.
   - `decorFence(plot, x, z, ctx): Model?`:
     - Choose Rail and Post. If either is missing, report each missing one and return nil.
     - Else build Model `DecorFence` with `LotArtMode = "Art"`. Per `decorPieces(x, z)`: Rail → `Segment_1`, Post → `EndPost`, pivot `lotPosition(plot, p.x, p.z, lotTop)` × `runYaw(p.dirX, p.dirZ, facing)`.
     - `Parent = plot`; no collision group (as today's FenceWooden); return.
3. **WorldService**:
   - Require `LotArt` (Shared) and `LotArtWorld` (`script.Parent`).
   - Right after `lotTop`, add `local ART_CTX = { lotPosition = lotPosition, lotTop = lotTop, facing = plotFacing, setCollisionGroup = setCollisionGroup, group = STRUCTURE_GROUP, reportMissing = reportMissing }`.
   - **Counter**: replace `checkout(parent, position)` with `buildCounter(plot: Model): Model`, placed after `bayDepth`. `position = lotPosition(plot, LotArt.COUNTER.x, LotArt.COUNTER.z, 0.6)`.
     - Art (`LotArtWorld.counter`): add Part `CounterBase` (today's size, colour, material and position), with `Transparency = 1`, `CanCollide = false`. Light parent = the art's descendant BasePart named `Register` if there is one, else `CounterBase`. `LotArtMode = "Art"`.
     - Else: today's primitive (CounterBase, Register, `PrimaryPart`), then `faceRoad(model, plotFacing(plot))`; `LotArtMode = "Primitive"`.
     - Both: `MapWorld.nightLight(lightParent, GameConfig.DayCycle.PlotLight)`, today's `CheckoutPrompt` code on `CounterBase`, `setCollisionGroup(model, STRUCTURE_GROUP)`.
   - **HQ**: move `HQ_COLORS` and `hqPrimitive` above `WorldService.build`, then add `buildHQ(plot: Model, level: number): Model`:
     - `hq = LotArt.hqLevel(level)`; `model = LotArtWorld.hq(plot, hq, ART_CTX)`.
     - If nil: for hq 1, `salesStand(plot, lotPosition(plot, -8, -4, 0.6))` plus `faceRoad`; else `hqPrimitive(plot, hq)`. Then `HqArtMode = "Primitive"`, `HqArtPath = LotArt.hqPath(hq)`.
     - Always set `HqLevel = hq` and `HqTier = tiers[hq].id`.
     - `applyHQVisual` keeps `findPlot`, destroys the old model, calls `buildHQ`, sets the plot's `HqLevel` and returns true; its own clamp goes.
   - **`build()`**: the stand line becomes `buildHQ(plot, 1)` and the checkout line `buildCounter(plot)`. Decor loop: `LotArtWorld.decorFence(plot, fence.x, fence.z, ART_CTX)`. If that returns nil, create Model `DecorFence` (`LotArtMode = "Primitive"`, `Parent = plot`) and call `cloneArt(decor, "Environment", AssetCatalog.Environment.FenceWooden, lotPosition(plot, fence.x, fence.z, 0.6))`.
   - **`buildReceiving`**: after each `Bay_<i>`, call `LotArtWorld.bay(folder, plot, index, lotPosition(plot, BAY_X, bayDepth(index), lotTop(plot)), ART_CTX)`. Art gives `bay.Transparency = 1` and `LotArtMode = "Art"`; else `"Primitive"`. The ReceivingArea stays.
   - **`syncBundles(bay, total)`**: `count = math.min(total, MAX_BUNDLES)`. If `count > 0` and `LotArtWorld.bundles(model, bay, count, ART_CTX)`, set `LotArtMode = "Art"` on `Bundles`; elseif `count > 0`, today's cylinder loop and `"Primitive"`. The `Total` attribute stays as today.
   - Add `lotTop`, `facing = plotFacing` and `reportMissing` to `FENCE_HELPERS`.
4. **`LotFenceWorld.build`** (requires ReplicatedStorage `ArtLibrary`, `LotArt`):
   - Choose Rail and Post.
   - Both Art: for each `fenceBoxes(growth)` id in order, make a Model with that id. For each `fenceSegments(growth)` piece of that box, clone: Rail → `Segment_<k>` (k from 1 per box), Post → `EndPost`. Pivot `CFrame.new(lotPosition(plot, x, z, lotTop(plot) - LotArt.FENCE_BASE_DROP)) * CFrame.Angles(0, LotArt.runYaw(dirX, dirZ, facing(plot)), 0)`. All BaseParts get `CastShadow = false`, with no CanCollide override. `LotArtMode = "Art"`.
   - Else: report each missing path and run today's Part branch unchanged (`LotArtMode = "Primitive"`).
   - `LotExpansionLevel` and the collision group stay as today.
