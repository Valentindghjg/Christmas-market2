## Decisions
| Topic | Decision |
|---|---|
| Where records live | **Company save** (`purchases`, schema 17): receipt IDs this save received (written in the same record as the grant), owned counts, boost time. **Player ledger** (new store, one key per player): purchase → save binding (`pending`), finished purchases (`done`), `robuxSpent`, per-player unlocks, passes counted. The profile is not changed. Co-op: a member's cash pack goes into the shared save; Robux spent and unlocks belong to the buyer. |
| Receipt rule | Grant only into the buyer's active save when `companies:isAvailable`. Otherwise `NotProcessedYet`. While the buyer is in the server but has no available save, the callback polls every 2 s for up to 60 s first (so a receipt replayed on join is granted once a save is played). |
| Cross-save safety | Bind the purchase to the save in the ledger **before** the grant. If it is bound to another save X, read X's record: receipt present → finish without a grant; no unexpired `_session` → rebind to the current save; otherwise `NotProcessedYet`. Safe because a session whose lock expired has already failed closed (`SaveFailClosedSeconds` 90 < `SessionLockSeconds` 120) and never saves again. |
| Acknowledge | `PurchaseGranted` only after: the grant, a successful save of the company record, and a successful ledger finish. Any failure → `NotProcessedYet`; a retry finds the receipt in the save and does not grant twice. |
| Unknown product ID | `NotProcessedYet` and a warning; never granted. |
| Game passes in co-op | A pass effect applies to a save while at least one player playing that save on this server owns the pass. |
| Robux spent | Receipts add `CurrencySpent` (Robux only). Each owned pass adds its price once (live price, else the config price; PROVISIONAL), at the first time this server sees it owned. |
| Prompting | Only the server prompts (`Shop.Prompt`). No ID (0) or `ready = false` → `ComingSoon`, never a prompt. Receipts are always honoured, even for a second starter pack bought through a race. |
| No random items | No roll, gacha or random reward anywhere. The starter pack's tree roll is dropped (version 2); its 5 decor items wait for decor (stored as owned count only); price stays 79. |
| Stacking | Cash multiplier = pass ×2 × boost ×2 (so ×4 with both, PROVISIONAL reading of "stacks with the pass"). Applies to customer sale cash only (not quests, not cash packs). The bonus also counts as revenue. |
| Boost clock | `CashX2` seconds count down only while the save is loaded (no offline time), 5-s pass, no dirty flag. |

`ready = false`: the target system (special trees, events CM2-45, decor) does not exist yet; "Coming soon", never prompted; a stray receipt grants the owned count only (stored inert).

**Company schema 17** (`BusinessState.SCHEMA_VERSION = 17`): `purchases = { receipts = { "<purchaseId>", … }, owned = { [productKey] = count }, boosts = { CashX2 = seconds } }`. Valid: `receipts` an array of ≤ `MaxSaveReceipts` strings of 1–64 bytes, oldest first; `owned` keys pass `ShopConfig.isKey`, counts integers 1–10000; `boosts` exactly `{CashX2}` integer 0..`BoostCapSeconds`. Migration 16 → 17 and the v1 path set `Purchases.new()`; `BusinessState.new` too; the final branch calls `Purchases.normalize` (drops the oldest receipts above the cap, clamps `CashX2`). Schema-16 servers fail closed on schema-17 records.

**Player ledger** (`PurchaseLedgerService`): store `ChristmasMarket2_Purchases_v1` (`STORE_NAME`), key `purchases:<SaveProfile.userIdText(userId)>` (`keyFor`, max 29 chars). Record v1:
`{ ledgerVersion = 1, userId, robuxSpent = 0, pending = { [purchaseId] = { productKey, saveId, robux, at } }, done = { { purchaseId, productKey, saveId, robux, at } }, passesCounted = { [passKey] = true }, unlocks = { [productKey] = true } }`.
Valid: integers ≥ 0 for `robuxSpent`, `robux`, `at`; `saveId` passes `SaveProfile.isSaveId`; product keys pass `isKey`; `pending` ≤ `LedgerPendingCap` entries; `done` a proper array ≤ `LedgerDoneCap`, oldest first; flag maps hold only `true`.

## Steps
1. **`ShopConfig.lua`** as above. Pure data plus the four lookups.
2. **`Purchases.lua`** (requires GameConfig, ShopConfig): `new()`, `isValid(state): boolean`, `normalize(state)`, `hasReceipt(state, purchaseId): boolean`, `apply(state, product, purchaseId): {cash, reputation, boostSeconds, rested}` (appends the receipt and trims the oldest above the cap; `owned[key] = min(count + 1, 10000)`; adds `grant.cash` to cash, `grant.reputation` to reputation, `grant.boostSeconds` to `CashX2` clamped at the cap; `rested` sets every `GameConfig.Staff.Roles` energy to `Staff.Energy.Max`; returns the amounts actually applied), `tick(state, seconds)` (CashX2 = max(0, CashX2 − seconds)), `cashMultiplier(state, perks): number`, `NO_PERKS` (frozen, all four false).
3. **`BusinessState`**: schema 17 per Data; `validate` calls `Purchases.isValid`. `placeOrder(state, requestId, species, size, quantity, timestamp, deliverySeconds: number?)`: `dueAt = timestamp + (deliverySeconds or GameConfig.DeliverySeconds)`.
4. **`PersistenceService:peekReceipt(companyId, purchaseId): (string?, string?)`**: one `_retry` of `UpdateAsync` whose transform always returns nil (no write). Result: nil or non-table record → `"Free"`; `purchases.receipts` (if a table) contains the ID → `"Applied"` (checked first, also for `_deletedAt`); `_session` table with `expiresAt > clock()` (any job, this one included) → `"Held"`; else `"Free"`. Store error → `nil, "LoadFailed"`.
5. **`PurchaseLedgerService`**: `new(store?, wait?)` (store defaults to `DataStoreService:GetDataStore(STORE_NAME)`); `newRecord(userId)`; every call is one `UpdateAsync` (3 attempts, waits 1 s and 2 s) whose transform resets its results first, builds from `newRecord` when nil, and returns nil (no write) for an invalid record (`"LedgerCorrupt"`) or when nothing changes. Store error → `"LoadFailed"`.
   - `read(userId): (record?, errorCode?)`, never writes.
   - `bind(userId, entry, replaceSaveId?): (status?, other?)` with `entry = {purchaseId, productKey, saveId, robux, at}`: in `done` → `"Done"`; pending with the same saveId → `"Bound"`; pending with `saveId == replaceSaveId` → rewrite saveId and at, `"Bound"`; other pending → `"Other", pendingSaveId`; new and pending full → `"Full"`; new → add, `"Bound"`. Errors return `nil, code`.
   - `finish(userId, entry, perPlayer): (record?, errorCode?)`: already in `done` → unchanged record; else remove from pending, append to done (trim oldest above cap), `robuxSpent += entry.robux`, `unlocks[productKey] = true` if perPlayer.
   - `countPasses(userId, prices: {[passKey]: number}): (record?, errorCode?)`: each key not in `passesCounted` → set it, `robuxSpent += price`.
6. **`CompanyPurchases.install(CompanyStateService)`** (pattern of `CompanyStaff`) adds methods: `setPerks(companyId, perks)` (stores a copy in runtime `self._perks`), `perksOf(companyId)` (stored or `NO_PERKS`), `priceTolerance(companyId): number?` (1.15 with vip, else nil), `cashMultiplierOf(companyId, state)`, `boostSeconds(companyId): number?`, `grantPurchase(companyId, purchaseId, product): (ok, errorCode?, applied?)` (inside `_withSession`: receipt present → applied false; else `Purchases.apply`, `BusinessState.record(state, "RobuxPurchase", result.cash)` when cash > 0, `revision += 1`, dirty. Then always `self:_save`; failure → `false, "SaveFailed", applied` (Amendment 1); not entered → `false, <code>`), `tickBoostsAll(seconds): (true, ticked, 0)` (healthy sessions only, no dirty, no revision). Module functions `CompanyPurchases.summary(service, companyId, state) = { cashBoostSeconds, perks }` and `CompanyPurchases.snapshot(state)` (deep copy of `purchases`).
   CompanyStateService deltas: require and install the mixin; `_dispatch(session, state, userId, request, companyId)` (handle passes companyId); `placeOrder(..., if self:perksOf(companyId).instantDelivery then 0 else nil)`; `CustomerOrderService.load(..., self:perksOf(companyId))`; summary gains `shop = CompanyPurchases.summary(self, companyId, state)`; `npcSettle` and `visitForTest` pass `self:cashMultiplierOf(companyId, state)` to `completeVisit`; `npcDecide` passes `priceTolerance = self:priceTolerance(companyId)` in the beginVisit options; `snapshotForTest` gains `purchases = CompanyPurchases.snapshot(state)`.
7. **Effects**:
   - `CustomerSimulationService.completeVisit(..., queueSeconds, cashMultiplier: number?)`: after a sale with multiplier > 1, `bonus = salePrice * (m − 1)`, cash and revenue += bonus, `sale.bonus = bonus`, history `SaleBonus`.
   - `beginVisit` options gain `priceTolerance: number?`, passed to `CustomerSelection.choose(state, profile, priceTolerance?)`, which uses `salePrice / (priceTolerance or 1)` for `canPurchase` and for the Demand price ratio; it still returns the real `salePrice`.
   - `CustomerOrderService.load(state, userId, orderNumber, carNumber, timestamp, perks?)` → `complete(..., perks)`: with vip, stars = min(5, stars + VipStarBonus) before the gain and the text key; with reputationX2 the gain × 2. `CompanyStaff.staffLoadOrder` passes `self:perksOf(companyId)`. Expiry (1 star) is unchanged.
8. **`StaffNpcService:restAll(companyId): number`**: sets the energy of every live record of the company to `Energy.Max`; returns the count.
9. **Protocol**: `Protocol.ShopActions = { Catalog = "Shop.Catalog", Prompt = "Shop.Prompt" }`; `Protocol.validateShopRequest(request)`: `validateEnvelope`; Catalog payload `{}` else `UnexpectedField`; Prompt payload exactly `{productKey}` else `UnexpectedField`, key failing `ShopConfig.isKey` → `InvalidProduct`.
10. **`MonetizationService.new(deps)`**. Deps: `companies`, `ledger`, `persistence`, `activeCompanyId(userId)`, `playersOn(companyId)`, `isPresent(userId)`, `ownsPass(userId, passId)`, `prompt(userId, kind, id)`, `productPrice(kind, id)`, `onApplied(userId, companyId, product)`, `setAttribute(userId, name, value)`, `wait(seconds)`, `clock()`, `shopConfig?` (default ShopConfig; tests inject IDs). Dep calls that can throw run in `pcall`.
    - `processReceipt(info)`: `info = {PlayerId, ProductId, PurchaseId, CurrencySpent}`; `byProductId` nil → warn `[ChristmasMarket2] unknown product <id>`, `"NotProcessedYet"`; else `processReceiptByKey(product.key, info)`.
    - `processReceiptByKey(productKey, info, options?)` (`options.present` only from the Studio hook): returns `"PurchaseGranted"` or `"NotProcessedYet"`. Checks: PlayerId a finite integer, PurchaseId a string of 1–64 bytes, product known; robux = CurrencySpent if an integer 0..1e6, else 0. A second call for an ID already in flight on this server → `NotProcessedYet`. Body (in `pcall`, the in-flight flag always cleared):
      1. Wait for a save: up to `ReceiptWaitSeconds / ReceiptPollSeconds` (30) times: not present (`options.present` or `isPresent`) → `NotProcessedYet`; `activeCompanyId` available → go on; else `wait(2)`. None → `NotProcessedYet`.
      2. `bind`: nil or `Full` → NPY; `Done` → `PurchaseGranted`; `Other X` → `peekReceipt("save:"..X)`: `Applied` → `finish` with saveId X, then `PurchaseGranted` (finish error → NPY); `Free` → `bind(entry, X)` must return `Bound`, else NPY; `Held` or error → NPY.
      3. `grantPurchase`; `applied` (also with a failed save, Amendment 1) → `onApplied` (rested staff, thanks notice) at once; then not ok → NPY.
      4. `finish`; error → NPY. Cache the record, set attribute `RobuxSpent`, return `PurchaseGranted`.
    - `onPlayerJoined(userId)`: `ledger:read` into the cache (failure → no cache), `RobuxSpent` attribute (0 without cache), then `refreshPasses(userId)`.
    - `refreshPasses(userId)`: for each Pass with id > 0, `ownsPass`; an error keeps the previous value (default false). Sets attribute `ShopPass<Key>` (e.g. `ShopPassVip`) true/false for all 4 passes; `countPasses` for owned passes not in the cached `passesCounted`; `refreshPerks(activeCompanyId)`.
    - `onPassPurchaseFinished(userId, passId, purchased)`: `purchased` and a known pass → owned, attribute, `countPasses`, `refreshPerks`.
    - `refreshPerks(companyId?, excludeUserId?)`: OR of the pass perks of `playersOn(companyId)` minus the excluded user → `companies:setPerks`.
    - `refreshPrices()`: `productPrice` for each id > 0; a number is cached as the live price.
    - `handle(userId, request)`: `validateShopRequest` → limiter `ShopLimit` (`RateLimited`) → action. **Catalog** → `{ok, data = {products = {{key, category, kind, price, state, grant}}, robuxSpent}}` in config order; state `ComingSoon` (id 0 or not ready), `Owned` (owned pass, or perPlayer key in the cached unlocks), else `Buy`. **Prompt** checks in order: `UnknownProduct`, `ComingSoon`, `AlreadyOwned` (pass owned / perPlayer unlocked), `ShopUnavailable` (perPlayer without cache), `NoActiveSave` (kind Product without an available active save), `BoostFull` (`boostSeconds + grant.boostSeconds > BoostCapSeconds`), `prompt` error → `PromptFailed`; success `{ok = true}`.
    - `robuxSpent(userId): number?`, `forgetUser(userId)`, test only `setPassesForTest(userId, passes)` (sets, attributes, refreshPerks) and `promptCountForTest()`.
