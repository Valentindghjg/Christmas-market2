Functions:
- `carStyle(n: any): (string, number)`. For a finite number, `m = max(1, floor(n))`; otherwise `m = 1`. Then `colour = (m-1)%6+1` and `body = ((m-1) + (m-1)//6)%3+1`; return `CAR_PATHS[body], colour`. Gives 18 combinations (the backlog's "number mod 3" gives 6).
- `truckYaw(facing) = LotArt.roadYaw(facing)`: the cab faces the road.
- `carYaw(facing)` = 0 when `facing == 1`, else π: the nose points into the lot.
- `cargoCount(x: any)` = finite ? `clamp(floor(x), 0, 9)` : 0.
- `bundleOffset(k): (rise, dz)`:
  - k 0–5: `(0, (k-2.5)*1.2)`
  - k 6–8: `(1.0, (k-7)*1.2)`
  - Offsets are relative to the cargo anchor; bundles lie along the anchor's X.

## Steps
1. `VehicleArt.lua` as above; requires only `LotArt`.
2. **VehicleWorld.lua**
   - `export type Ctx = { part: <WorldService part signature>, reportMissing: (string, string) -> () }`.
   - Art via `LotArt.choose(ArtLibrary.root(ReplicatedStorage), ArtLibrary.find, path)`; none: `ctx.reportMissing(path, code)`, primitive.
   - Attributes `VehicleKind` (`Truck`/`Car`), `VehicleArtMode` (`Art`/`Primitive`), `VehicleArtPath`.
   - `truck(parent, pose: CFrame, ctx): Model`, named `DeliveryTruck`. The art keeps the pipeline's collision. The primitive is built in model space (front -Z, ground at y 0), then `PivotTo(pose)`:

     | Part | Size | Position | Colour, material |
     |---|---|---|---|
     | `TruckBody` | 5×3×12 | (0,2,0) | 198,42,42, Metal |
     | `Cab` | 5×3.5×4 | (0,4.2,-4) | 243,239,224, Metal |
     | `Wheel` ×4 | 0.6×1.5×1.5, Cylinder | (±2.6,0.75,±4) | 27,27,27, Rubber |

     `TruckBody` is the PrimaryPart, with `PivotOffset = CFrame.new(0,-2,0)`.
   - `car(parent, name, pose: CFrame, n: number, ctx): Model`, styled by `carStyle(n)`.
     - Art: set every BasePart to `CanCollide = false` and `CanTouch = false`. Colour `FindFirstChild("Paint", true)` when it is a BasePart; if it is missing, call `reportMissing(path.."/Paint", "InvalidArtAsset")`.
     - Primitive: today's `car()` parts at `CFrame.identity`, `Body.PivotOffset = CFrame.new(0,-1.6,0)`, then `PivotTo(pose)` (fixes the low car).
   - `cargoTop(model): CFrame`, in this order:
     1. The `WorldCFrame` of the `CargoAnchor` Attachment under `PrimaryPart`.
     2. A `RoofRack` child: its CFrame raised by half its height.
     3. `GetPivot() * CFrame.new(TRUCK_ or CAR_CARGO_FALLBACK)`, chosen by `VehicleKind`.
   - `loadCargo(truck, arriving: any, ctx)`:
     - When `cargoCount` is 0, do nothing.
     - Create Model `Cargo` with attributes `Bundles` and `VehicleArtMode`.
     - Bundle k goes at `pose = cargoTop(truck) * CFrame.new(0, rise, dz)`.
     - Art (`LotArt.PATHS.Bundle`): a clone with `CanCollide` and `CanQuery` false.
     - Primitive: `ctx.part(cargo, "Bundle", 4×1×1, …, 23,83,52, Grass)`, Cylinder, `CFrame = pose * CFrame.new(0,0.5,0)`, no collide.
   - `unloadCargo(truck)`: destroy `Cargo`.
3. **WorldService**
   - Remove local `truck`, `car`, `CAR_COLORS`, `ROOF_RACK_TOP`; add `VEHICLE_CTX = { part = part, reportMissing = reportMissing }`.
   - `truckStart` = `CFrame.new(lotPosition(plot, TRUCK_X, TRUCK_START_DEPTH, ROAD_TOP)) * CFrame.Angles(0, truckYaw(plotFacing(plot)), 0)`.
   - Stop pose y `TRUCK_LANE_TOP`.
   - `syncReceiving`:
     - Spawn: `VehicleWorld.truck(plot, start, VEHICLE_CTX)`, `loadCargo(truck, <pull-in bay view.arriving>)`, `drive` (unchanged).
     - Leaving: `unloadCargo(leaving)` before `drive`.
   - `parkedAt`: X and Z as today, y = `lotTop(plot) + PARKING_RISE`, multiplied by `CFrame.Angles(0, carYaw(plotFacing(plot)), 0)`.
   - `roadEntry(parked) = CFrame.new(parked.X, ROAD_TOP, 0) * parked.Rotation`.
   - Order cars use `VehicleWorld.car(..., orderNumber, VEHICLE_CTX)`; visit cars pass `seq`. Durations and XZ paths unchanged.
   - `decorateCar`: label height `CarNumber.height + CAR_LABEL_LIFT` for `Art`; label and prompt stay on `PrimaryPart` (`ArtRoot`), so `findOrderTarget` and reach need no change.
   - `attachRoofTree`: `top = VehicleWorld.cargoTop(carModel)`; primitive tree `top * CFrame.new(0, ROOF_PRIMITIVE_LIFT, 0) * CFrame.Angles(rad 90, 0, 0)`; art tree today's formula with `top` for `rackTop`.
   - Export `WorldService.carCargoTop = VehicleWorld.cargoTop`.
4. **Step 73 `VEHICLE_ART`** (`Steps/Vehicles.lua`, needs `{ "02a" }`; helpers as in `Steps/LotArt.lua` and `Steps/Trees.lua`)
   - All free plots (step 66 `bundleCheck`), ≥ 2, both road sides (Amendment 1); (a) on all at once, then wait.
   - (a) Truck arrives:
     - Call `syncReceiving(P, {[1] = {speciesId = "NobleFir", counts = {Small=0,Medium=0,Large=0}, total = 0, arriving = 12, arrivesIn = TruckPullInSeconds}})` and wait `TruckPullInSeconds + 1` s.
     - `DeliveryTruck` is `Art`, `Vehicles/SupplierTruck`, pivot within 0.05 of lot (46, -22) y 0.05, `sign(LookVector.Z) == facing`.
     - `Cargo` holds 9 `Bundle`s, each bottom ≥ `carCargoTop.Y - 0.05` and each top ≤ `carCargoTop.Y + 2.1`.
   - (b) Same call, `arriving = 0, arrivesIn = -1`: `Cargo` gone at once, no `DeliveryTruck` after `TruckLeaveSeconds + 2` s.
   - (c) Cars arrive:
     - `syncCustomerOrders(P, {orders = …})`: 9301–9304 on spaces 1–4, fields as step 64 (b), callbacks nil; wait 2.5 s.
     - Each `CustomerCar_<n>`: `Art`, path `carStyle(n)`; `Paint.Color` = `CAR_COLORS[colour]` (±1/255); pivot within 0.05 of the parking centre, y 0.82; `sign(LookVector.Z) == -facing`; `PrimaryPart` is `ArtRoot` with `Label` and `LoadOrder` and equals `findOrderTarget(P, "Car", n)`.
   - (d) Cars leave loaded:
     - `syncCustomerOrders(P, {orders = {}, loadedNumbers = 9301..9304})`: each `LeavingCar`'s `RoofTree` bottom within -0.05..0.3 of `carCargoTop(car).Y`; none left after 5 s.
   - Then call `syncReceiving(P, nil)`. PASS detail: `trucks=<k> cars=<4k>`.
5. **Step 64 (c)**: rack top = `WorldService.carCargoTop(car).Position.Y` instead of `RoofRack`; tolerance unchanged.
