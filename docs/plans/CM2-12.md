**Build rules (all species):**
- `star_cone(part, key, R, r_top, depth, loc, twist, p, inner, droop)` (bmesh, in `tree_common.py`): bottom ring of 2p vertices alternating radius R (lowered by droop × depth) and R × inner; top ring of p vertices at r_top = 0.15 R; closed bottom face, no gaps.
- Tier i of n (0 = bottom): radius R(1 − taper·i/(n−1)); tier height = crown/n × overlap; crown runs from t·H to H − leader; twist from `K.seed(<fixed per model>)`.
- `NeedlesCore` (core key): an 8-sided cone inside each tier, radius 0.55 × tier radius, filling the notches.
- `Snow` (SnowWhite): a star_cone hugging each tier's upper surface (from 0.5 to 0.5 + snow of the tier height, scaled 1.04).
- Leader: a cone in the needle key, r 0.12 R, height 0.10 H (BlueSpruce 0.14 H).
- `Trunk` (BarkBrown): 6-sided cylinder, radius 0.11 R. `RootFlare` (BarkBrownShade): a 6-sided frustum, r 0.2 R → 0.11 R, height 0.04 H.
- Creation order (= MeshPart names): Trunk, RootFlare, NeedlesCore, Needles, Snow, then Frost/Topper/Berries; ≤ 7 MeshParts.
- `K.collider("Tree", (1.1R, 1.1R, H), (0, 0, H/2))`, `K.attachment("TreeBase", (0, 0, 0))`; origin = trunk foot.

**`build.py` (3 lines + docstring):** `sys.path[:0] = ["tools/art/kit", "assets/art/source/Trees"]`; `import cm2_kit as K, tree_common as T`; `K.run(lambda: T.build("<ID>", "<Size>"), tier="A")`.

**Review latitude:** in render rounds any Species-table number may change by up to ±15%; H, R limits, budgets, keys and part names are fixed. Final values: `SPECIES` and DECISION_LOG.

## Steps
0. **Doctor branch:** `lune run tools/art/art.luau doctor`.
   - Exit 1 (no Blender): stop and report; the task is BLOCKED.
   - Exit 2 (key or creator missing): **branch N**. Steps 1, 6 and branch I of step 7 are "BLOCKED by PC-2"; go to step 2.
   - Exit 0: **branch I**, go to step 1.
1. **Probe (branch I):** `lune run tools/art/art.luau probe`. Expect `[ART] probe OK yaw <θ> scale <k> asset <id>`.
   - If θ ≠ 0, set `IMPORT_YAW_DEGREES = θ` in `Config.luau`.
   - Keep the probe fixture's `version` bump and `upload` fields for the first commit.
   - An HTTP 4xx/404 or `ART_AXIS_MISMATCH`: record the code, status and body (≤ 200 chars); continue as branch N (the planner amends Config).
2. Add the palette keys. Write `tree_common.py`, the 14 `build.py` and the 14 `asset.json`.
3. Per model: build (`blender -b --factory-startup --python <dir>/build.py -- --out <dir>/model.blend`) → `CM2_KIT_OK`, then `art.luau export <artPath>`. From `_build/<artPath>/report.json` check:
   - `size[2]` (Y) = H ± 0.2;
   - `max(size[1], size[3]) / 2` ≤ R + 0.05;
   - `triangles` ≤ maxTriangles;
   - attachment `TreeBase` at (0, 0, 0).
4. `art.luau render <artPath>`. Look at `preview_34.png` and compare with the checklist (liked/disliked images once per task). At most 3 rounds per species (for all its sizes). A species still failing after round 3 → report it; none of its sizes is committed.
5. Copy each `preview_34.png` to `assets/art/previews/<artPath>.png`.
6. **Branch I:** `art.luau upload <artPath>` then `normalize <artPath>` for all 14 → `[ART] normalized … yaw <θ> scale <k>`.
7. **Branch I:** `rojo build` both projects; `art.luau verify release.rbxlx` → `[ART] 14 integrated, 0 pending, 0 failed`.
   - Branch N: the same command must print `0 integrated, 14 pending, 0 failed`.
8. Docs (MODEL_INTEGRATION, DECISION_LOG). Run `unix2dos` on each staged doc that `git ls-files --eol` shows as `w/mixed` (CM2-AP amendment).
9. Report per model: `CM2_KIT_OK` line, report size, rounds and items fixed; plus the branch and BLOCKED items.
