## Goal
The Lot Manager's Employees tab lists Cashier, Lot Worker and Lot Manager with one-time cost, a Hire button, each hired employee's energy and status, and "X / 2 hired". The player can move the staff break area anywhere valid on the lot; resting staff follow it.

## Data and config
- `GameConfig.Employees.BaseCapacity = 2` (OBSERVED). No schema change (schema 16 from part a).
- Summary `staff` sub-table (from `CompanyStaff.summary(session, state)`): `{ hiredCount, capacity, breakArea = {x, z, rotation}, roles = { {id, hired: boolean, hireCost, locked: boolean, energy: integer, status: "Working"|"OnTheWay"|"Resting"|"Arriving"|nil} } }` in the order Cashier, LotWorker, LotManager; `status` nil when not hired; `energy` from `staffLive` else `staffEnergy`.

## Steps
1. **Protocol**: `Protocol.Actions.StaffMoveBreakArea = "Staff.MoveBreakArea"`, added to the known-action set. `EmployeeHire` accepts `"Cashier"`, `"LotWorker"`, `"LotManager"`. `StaffMoveBreakArea`: only keys `x`, `z`, `rotation`; `x`, `z` finite numbers with `|v| ≤ Placement.CoordinateLimit` and `v · 2` an integer; rotation one of 0, 90, 180, 270; else `InvalidBreakArea`.
2. **Staff.lua**: `Staff.moveBreakArea(state, x, z, rotation) -> (boolean, any)`: `checkBreakArea(Stocking.layoutInput(state), x, z)`; refusal → `(false, code)`; else `state.breakArea = {x = x, z = z, rotation = rotation}` (fresh table) and `(true, table.clone(state.breakArea))`.
3. **GameConfig**: `Employees.BaseCapacity`.
4. **EmployeeService.hire(state, employeeId)**: the check order in Decisions; capacity helper `EmployeeService.capacity(state): number`, `EmployeeService.hiredCount(state): number`.
5. **CompanyStaff** (mixin): `noteStaff(companyId, role, status: string?, energy: number?)` (runtime `session.staffLive`, no section needed, no dirty); `CompanyStaff.summary(session, state)`; `setBreakAreaChangedHandler(fn: (companyId, area) -> ())`; `_notifyBreakArea(companyId, session)` calls it with a clone in pcall (warn on error).
6. **CompanyStateService**: `StaffMoveBreakArea` in `MEMBER_ACTIONS`; `_dispatch` branch `Staff.moveBreakArea(state, payload.x, payload.z, payload.rotation)` with response flag `breakAreaChanged`; `handle` calls `_notifyBreakArea` and strips the flag; summary adds `staff = CompanyStaff.summary(session, state)`. **StaffNpcService**: after each step `companies:noteStaff(companyId, role, uiStatus, floor(energy))`, on `_remove` `noteStaff(companyId, role, nil, nil)`; the re-route rule above using `record.breakKey = "x:z:rotation"`. **main.server**: `companies:setBreakAreaChangedHandler` → `StaffNpcWorld.syncBreakArea(plots:getPlot(companyId), area)` when the plot exists.
7. **EmployeesTab.lua** (tab contract; reads only `summary.staff`; `render(nil)` shows `loading`): page layout in offsets, built with `UiKit.label`/`UiKit.button`, colours `UiKit.Colors`:
   - Title `employees` (TextSize Title) and line `staffHiredCount` ("%d / %d hired").
   - One card per role (height 132, pitch 140, full page width − 16): name, role sentence, cost line `staffCost` with thousands separators ($1,200), status line `staffStatus` ("Energy %d%% · %s") plus an energy bar (Frame 200 × 10, fill width ∝ energy, `UiKit.Colors.Gold` fill) when hired, and a 140 × 44 button on the right: `staffHire` / `staffHireConfirm` / `staffHired` (inactive) / `insufficientFunds` (inactive when the HUD cash is below the cost) / `staffLockedShort` (inactive, with the card's locked line `staffLocked`).
   - Under the Cashier card when it is not hired: `staffNoCashier`. Footer: `staffNoWages`, then `breakAreaTitle` and a 200 × 44 button `breakAreaMove`.
   - Hire sends `context.request("Employee.Hire", {employeeId})`, then `context.refresh()`; failures show `errorStatus` with the key from the error table (`EmployeeLocked` → `staffLocked`, `EmployeeCapacity` → `staffCapacityFull`, `InsufficientFunds` → `insufficientFunds`, `AlreadyHired` → `staffHired`, `RateLimited` → `saveErrorRateLimited`).
   - Move button: `BreakAreaMode.start(player:GetAttribute("PlotId"), context.request, context.refresh)`.
8. **BreakAreaMode.lua** (ModuleScript in `src/client`): `start(plotId: string, request, onDone: () -> ())`. Claims modal `"BreakAreaMode"` (closes the Lot Manager). Copies of StockingMode's `plotModel`, `plotCenter`, `plotFacing`, `snapHalf`, `groundY`, `worldPoint`, `toLotFrame`, `raycastLot` (same code; StockingMode unchanged). Pointer: starts at the current area (plot attributes `BreakAreaX/Z`); on PC it follows the mouse each `RenderStepped`; on touch a short tap (< 0.3 s, < 12 px) sets it. Ghost: Part `BreakAreaGhost` 8 × 0.2 × 8, Transparency 0.5, green `(114, 172, 113)` / red `(196, 58, 52)`, `CanCollide`/`CanQuery`/`CanTouch` false, in a client folder. Validity: `Staff.checkBreakArea({lotExpansion = plot "LotExpansionLevel", trees from DisplayedTrees attributes}, x, z)`; reason line keys: `OutsideLot` → `stockOutsideLot`, `KeepClear` → `stockKeepClear`, `TooClose` → `breakAreaTrees`. Bar `BreakAreaBar` (bottom centre, UiTheme metrics like the stocking bar): header `breakAreaMove`, hint `breakAreaHint`, reason line, buttons `Rotate` (`breakAreaRotate`, +90), `Place` (`breakAreaPlace`, inactive while invalid or in flight), `Cancel` (`breakAreaCancel`); keys R, Enter, Q. Place sends `Staff.MoveBreakArea {x, z, rotation}`; ok → reason line `breakAreaMoved`, exit after 1.5 s and `onDone()`; error → reason text. Exit destroys the ghost, the bar and every connection and releases the modal.
