## Skill checks
- data: schema 23 `eventPurchases` (migration, legacy-v1, `new` set `{}`); `validate` fails closed on bad shapes; keys checked by format only, so config changes never brick a save.
- networking/security: payload exactly `{eventId, itemKey}`; price, limit, decor only from `EventConfig`; replay `DuplicateRequest`; all checks before the first change; `companies:handle` limiter (10 / 10 s).
- game-design: the pack is a cash sink, not revenue; price and limit PROVISIONAL; Robux items never prompted.
- gui/input: buttons >= `MinTouch`, inside the panel at 666x374; server state only; one request in flight; `UiTheme`/`UiKit` only.
- localization: full-sentence EN/DE keys, numbers via format keys. luau: `--!strict`, NaN/inf guards, fixed integer dates (no `os.date`).
- architecture/tooling: pure shared `EventConfig` (data), `EventCalendar` (logic); server mixin `CompanyEvents` (CompanyProgression pattern); new modules in `run.luau`.

## Steps
1. **`EventCalendar.lua`** (`--!strict`; requires EventConfig):
   - `active(now: number): Event?` — the event with `startsAt <= now < endsAt`; nil for NaN/inf.
   - `view(now): {id: string, titleKey: string, endsIn: number}` — `endsIn = math.max(0, math.ceil(endsAt - now))`; none -> `{"", "", 0}`.
   - `item(event, key: unknown): Item?`
   - `countdown(seconds: number): (string, number, number)` — `>= 86400` -> `"eventEndsDays", d, h`; `>= 3600` -> `"eventEndsHours", h, m`; else `"eventEndsMinutes", m, s` (negative/NaN -> 0, 0).
   - `isPurchases(value: unknown): boolean` (Data rules).
2. **AdventCalendar**: `isDecorItem` also accepts `EventConfig.isDecorItem(value)` (`-- CM2-45: event decor shares the crate`).
3. **`CompanyEvents.lua`** (server mixin; requires GameConfig, BusinessState, EventCalendar, ShopConfig):
   - `CompanyEvents.buy(state, payload, now): (boolean, any)`, in this order: no active event or `payload.eventId ~= event.id` -> `EventClosed`; item nil -> `InvalidItem`; `bought >= item.limit` -> `PurchaseLimit`; `state.cash < price` -> `InsufficientFunds`; then `cash -= price`, `spent += price`, `BusinessState.record(state, "EventPurchase", -price)`, each decor `min(old + count, GameConfig.Advent.DecorMaxCount)`, `eventPurchases[eventId][itemKey] = bought + 1`. Returns `{eventId, itemKey, price, bought, decor = {[id]: newCount}}`.
   - `CompanyEvents.summary(state, now): any?` — nil without an active event; else `{id, titleKey, endsIn, items}`: cash items `{key, kind = "Cash", price, limit, bought}` in config order, then each `robuxItems` key `{key, kind = "Robux", price = ShopConfig.byKey(key).price, ready = entry.ready and entry.id > 0}`.
   - `install(CompanyStateService)`: `eventNow(): number` (`_eventNowOverride or _clock()`), `eventView()`, `setEventNowForTest(at: number?)`, `clearEventPurchasesForTest(companyId): boolean` (`eventPurchases = {}`, `revision += 1`, dirty; false without a healthy session).
4. **BusinessState**: `SCHEMA_VERSION = 23`; `new`, migration `-- Schema 23 (CM2-45): event shop purchases per save.` and legacy-v1 set `eventPurchases = {}`; `validate` adds `EventCalendar.isPurchases`. Tests pinning 22 move to 23.
5. **Protocol**: `Actions.EventBuy = "Event.Buy"` (comment `-- CM2-45: buy an event shop item (companies:handle)`) in `actionSet`; validator: other keys -> `UnexpectedField`; `eventId` or `itemKey` not `ShopConfig.isKey` -> `InvalidItem`.
6. **CompanyStateService**: `CompanyEvents.install`; `EventBuy` in `MEMBER_ACTIONS`; `_dispatch` branch `CompanyEvents.buy(state, payload, self:eventNow())`; summary field `event = CompanyEvents.summary(state, self:eventNow()), -- CM2-45`; `snapshotForTest` adds a deep copy of `eventPurchases`.
7. **main.server.lua**: `publishEvent()` sets `ReplicatedStorage` `EventId`/`EventEndsIn` from `companies:eventView()`; run at start and by `every(EventConfig.RefreshSeconds, "event", …)` (`true, 0, 0`); test context `publishEvent`.
8. **StudioTestService** (errors as `adventNow`): `eventNow {at: int 0..2^53}` or `{clear = true}` -> `companies:setEventNowForTest`, `context.publishEvent()`, `success(true)`; `eventReset {userId}` -> `NoActiveSave` or `success(companies:clearEventPurchasesForTest(companyId))`.
9. **`src/client/EventShopPanel.lua`** (`EventShopPanel.new(context): {render: (summary: any?) -> ()}`; AdventPanel/QuestPanel pattern, UiTheme/UiKit only):
   - `UiKit.screenGui("EventUI", 15)`; `addRailButton("EventButton", "eventButton", 35)`, visible iff `CompanyReady` and `EventId ~= ""`.
   - Frame `EventShopPanel`: `Title` (22, `titleKey`), `Countdown` (Small), `Hint` (Small, `eventHint`), `List` ScrollingFrame + `UIListLayout` (padding 6, AutomaticCanvasSize Y), `Footer` with `Status` and `CloseButton` (Sand, 120 wide, `eventClose`); `UiKit.bindDialog(..., UiTheme.Dialogs.Event)`.
   - Rows `Item_<key>` (Row, height 64): `Name`, `Info` (Small, wrapped), `BuyButton` (right, 120 x `MinTouch`). Cash: `eventItem<key>`, `eventDesc<key>`, `eventPriceCash` with `UiTheme.formatMoney(price)` Gold active; `bought >= limit` -> `eventBoughtButton` Sand inactive.
